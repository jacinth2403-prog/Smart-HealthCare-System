# Smart HealthCare System

An AI-powered healthcare supply chain decision-support system that helps healthcare facilities predict medicine demand, identify potential stock-outs, and make proactive inventory redistribution decisions.

## Problem

Healthcare facilities can face medicine shortages due to changing demand, limited inventory, and supply-chain delays. At the same time, other facilities may have excess stock.

The goal of this project is to use AI to identify potential shortages early and support better inventory management.

## Solution

The system will:

- Forecast future medicine demand.
- Predict potential medicine stock-outs.
- Identify facilities with surplus inventory.
- Recommend possible medicine redistribution.
- Use Google Gemini to explain predictions and recommendations.
- Display insights through an interactive web dashboard.

## Technology Stack

- Frontend: React, TypeScript
- Backend: Python, FastAPI
- Machine Learning: Pandas, NumPy, Scikit-learn, XGBoost
- Generative AI: Google Gemini
- Database: Firebase Firestore
- Visualization: Recharts
- Development: VS Code, Jupyter, Git, GitHub
- Deployment: Firebase / Google Cloud

## Data

The project will use publicly available healthcare and supply-chain datasets, including government healthcare data where suitable.

If real facility-level inventory data is unavailable, synthetic data will be used for prototype demonstration and clearly identified as synthetic.
